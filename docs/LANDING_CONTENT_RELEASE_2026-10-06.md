تصحيح اسم د. نجوى **باطرفي** وتخصص صفحتها في بيانات البحث والبيانات المنظمة. تخصيص بيانات البحث لصفحات الأنف، شد الوجه، التحضير لاستشارته، ومصدر تيك توك لتطابق المحتوى الفعلي.

## المحافظة على المحتوى والإدارة

- التحديث يضيف قسمًا بعد HTML القائم؛ يحفظ الأصل حرفيًا دون إعادة توليد القالب، ويكتب `htmlContent` فقط. لا يغيّر الأسعار أو العروض أو النماذج أو الخيارات أو الهاتف أو بيانات الحملات أو إعدادات Webhook أو حالة النشر أو الرابط أو `noindex`.
- لا يحدث صفحات المسودة أو الصفحات المستبعدة من الفهرسة. روابط الخدمات والأطباء تُختار من السجلات المنشورة وقت التنفيذ؛ لا يُخترع توفر خدمة أو ارتباط طبيب بها.
- الإضافة لا تحمل JavaScript أو نماذج أو صورًا جديدة، باستثناء أيقونة واتساب الصغيرة لسهام. الأسئلة تستخدم `details/summary`، وتنسيق القسم محصور في عناصره مع معالجة عرض الجوال.
- يحمي التحديث بشرط تطابق `id` و`updatedAt` وHTML القائم وحالة النشر. تعديل الإدارة المتزامن يؤدي إلى تجاوز الصفحة بدل الكتابة فوقه.
- تعديل الصفحة وعلامة الإصدار والسجل تُحفظ في معاملة واحدة. علامة `SiteSetting` صغيرة تحفظ المعرف والطول وبصمات SHA-256 فقط؛ لا تحفظ HTML كاملًا أو بيانات مرضى أو أسرارًا. تبقى العلامة عند تنظيف السجلات، لحفظ قرار الإدارة إذا عدّلت أو حذفت الإضافة لاحقًا.
- يشغّل `prebuild` الموجود الإصدار على Render فقط. البناء المحلي العادي لا يكتب في قاعدة بيانات الإنتاج. لا تغيير في مخطط Prisma أو إعدادات الاستضافة.

## التحقق قبل النشر

نجح البناء الإنتاجي وTypeScript و12 اختبار SEO و11 اختبار تتبع الحجز و14 اختبارًا لصفحات الهبوط. Lint: لا أخطاء، وتحذير قائم في `ImagePicker.tsx` خارج التعديل.

مقارنة GET لصفحات الهبوط الـ19 ومعاينة الإضافات عبر المنقّي الفعلي أكدت بقاء جميع نماذج HTML وH1 الأصلية، وعدم تكرار سؤال قائم، واختيار الروابط من خريطة الصفحات المنشورة. الإضافة لكل صفحة نحو 4.5–6.4 كيلوبايت، وفق المعاينة ذات أسماء روابط مختصرة؛ لا يضاف تحميل مكتبات أو صور للمحتوى.

فُحصت الأسئلة القابلة للفتح، عرض الجوال 390 بكسل، صفحة دليل الجسم، عروض البشرة وفقاعة سهام. الفقاعة ثابتة وأيقونتها محملة، وتقع داخل الشاشة.

فحص الإنتاج الأول أكد HTTP 200 وبيانات البحث وcanonical وتعليمات الفهرسة للـ104 روابط المنشورة. المقارنة التفصيلية كشفت صفحات تستخدم `seoSlug` مختلفًا عن `slug` الداخلي، منها `offers` على رابط `exclusive-offers`. لذلك يبحث الإصدار بالمعرفين، ويختار المحتوى حسب رابط SEO مع حفظ كليهما. علامة الإصدار نفسها تمنع تكرار الإضافة للصفحات التي اكتمل تحديثها في الدفعة الأولى.
