# إصلاحات SEO والأداء — ٤ أكتوبر ٢٠٢٦

هذه الدفعة مبنية على فحص الكود وطلبات HTTP وتدقيق المتصفح. لا تمثل قياسًا لتحسن ترتيب Google أو الزيارات. اتصال Search Console المتاح أعاد قائمة مواقع فارغة.

## التغييرات

- عرض محتوى المقالات القديم المكتوب بـ Markdown و`<br>` كعناوين وفقرات وقوائم وتأكيد نصي، مع الإبقاء على النص الأصلي في قاعدة البيانات. تعقيم HTML المنسق عند العرض.
- إظهار النسخة الإنجليزية للمقال و`hreflang` فقط عند وجود عنوان وملخص ومحتوى إنجليزي؛ ووسم النص العربي باتجاهه ولغته حتى عند اختيار واجهة إنجليزية.
- إعطاء كل صفحة من صفحات المجلة عنوانًا وcanonical مستقلًا، وإرجاع الصفحات غير الصالحة عبر `notFound` و`noindex`.
- استخدام تواريخ التعديل الفعلية في sitemap وإهمال التواريخ المجهولة. الحفاظ على الروابط الصحيحة التي تتضمن أحرفًا كبيرة أو عربية.
- إصلاح رابط «عملية شد الصدر» إلى `breast-lift` في صفحات الأطباء، وتحويل الرابط القديم بـ308 مع الحفاظ على query string.
- ضبط عناوين ووصف صفحات الخدمات بحسب اللغة؛ وتجنب توريث عنوان الخدمة الأساسية نفسه لصفحة خدمة مختلفة، مع الحفاظ على نص SEO المخصص المختلف.
- إضافة أسئلة مرئية طبيعية عن أفضل خيار، واختيار الطبيب، والتكلفة والتعافي في صفحات الخدمات المناسبة. لا توجد أسعار أو ضمانات أو ادعاءات تفوق جديدة، ولا وعد بنتائج FAQ غنية.
- تأجيل reCAPTCHA إلى اقتراب النموذج أو التركيز عليه؛ الإرسال ما زال يطلب توكنًا جديدًا. صور دوّارات الأطباء والمجلة أسفل الرئيسية تستخدم التحميل الكسول.
- إضافة أولوية تحميل `fetchpriority=high` لصور الشعار التي تحمل أصلًا `priority`، بعدما عرّف قياس Lighthouse الشعار كعنصر LCP وأثبت نقص هذه الإشارة. صور الشعار العادية بلا `priority` تحتفظ بأولويتها الافتراضية.
- حفظ تاريخ النشر الأصلي عند تحرير المقال أو إعادة نشره لاحقًا.
- إخفاء تعليمات مورد تحريرية منشورة ضمن شهادات جهاز، دون اختلاق اعتماد بديل.

## التحقق قبل الدفع

- `npm run typecheck`: ناجح.
- `NODE_ENV=production npm run build`: ناجح، ومزامنة standalone ناجحة.
- `npm run lint`: صفر أخطاء؛ تحذير قديم واحد في `ImagePicker.tsx` خارج نطاق التغيير.
- `npm run test:seo`: ٩ اختبارات ناجحة، تشمل وصول أسئلة الاختيار إلى المسارات المنشورة الفعلية.
- `npm run test:lead-tracking`: ١١ اختبارًا ناجحًا.
- `npm run test:smoke`: ناجح على standalone محلي مع قاعدة البيانات معطلة. صُحح توقع قديم لـsitemap index وتوقع خاطئ لـAPI مستندات غير مُنفذ؛ لم تُغيّر حماية البوابة.
- `npm run test:seo-smoke`: فحص HTTP للcanonical واللغات والصفحات غير الصالحة والتحويل وsitemap. يصلح للتحقق من الموقع الحي لأنه يقرأ فقط.
- اختبار فعلي لمكوّن المقال باستخدام عينة محفوظة من المقال الحي: ٣ عناوين H2 وقائمتان وتأكيد نصي؛ لا رموز `<br>` مرئية، ولا H1 مكرر. اختبار HTML احتفظ بالتنسيق وحذف script ومعالج حدث من العينة.
- اختبار المتصفح للنموذج مع محاكاة محلية: صفر تحميل reCAPTCHA أول الصفحة، تحميل واحد عند الوصول للنموذج، وطلب توكن جديد عند إرسال محاكى. لم يُحفظ طلب مريض.
- قياس تخطيط الخدمة بعرض ٣٩٠ بكسل: لا تجاوز أفقي للمحتوى الجديد.

## أعمال تحتاج أدلة إضافية

تحسين صور R2 والكاش وLCP يحتاج قياسًا ومعالجة مستقلة. لا تزال مراجعة نسبة النص الطبي إلى كاتبه ومراجعه، وترجمة المحتوى الناقص، ومراجعة بقية عناوين الموقع مطلوبة. لا يُحسم دمج صفحات متشابهة أو حذفها أو تحويلها دون مراجعة بيانات البحث ومحتواها.

هذه الدفعة لا تغيّر مخطط قاعدة البيانات أو إعدادات النشر أو سياسة الأمان أو تكاملات التتبع. الرجوع عن كود الدفعة يتم بـgit revert لالتزام الإصلاح ثم دفعه إلى main؛ لم تُنفّذ عملية إعادة كتابة لمحتوى الإنتاج أو ترحيل بيانات ضمن هذه الإصلاحات.
