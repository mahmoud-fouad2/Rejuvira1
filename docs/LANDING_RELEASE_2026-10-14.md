# إزالة بطاقة أكتوبر وتحسين صفحات الهبوط — 14 أكتوبر 2026

## نطاق الإصدار

- حصر 21 صفحة هبوط منشورة من خريطة الموقع، وقراءة كل صفحة على حدة.
- تأكد وجود البطاقة في `customBodyCode` العام: كتلة مستقلة باسم
  `addRejuveraBreastCancerCard` ومعرّف `rejuvera-breast-awareness`.
- إزالة هذه الكتلة تحديدًا من المخرجات قبل إرسال بيانات التكامل إلى المتصفح.
  لا يشمل ذلك المقالات أو المحتوى الطبي عن سرطان الثدي.
- عند بناء Render، تنظيف حقول التكامل المحفوظة نفسها داخل معاملة تحفظ نسخة
  استرجاع في AppLog من نوع `cms-integration:retire-awareness-2026-10-14`.
  التحديث مشروط بالقيمة ووقت آخر تعديل؛ أي تعديل متزامن يُترك كما هو، وفشل
  حفظ النسخة يلغي الحذف. لا تُسجل الأكواد في مخرجات البناء.
- يمنع حفظ التكاملات إعادة إدخال الكتلة المتقاعدة ذاتها، مع الحفاظ على الأكواد المجاورة.

## المحتوى

- نصوص مستقلة للصفحات الـ21 في `src/lib/landing-search-content.ts`، تتضمن
  42 سؤالًا وجوابًا جديدًا وموضوعات اختيار الطبيب والخدمة والتكلفة والتحضير.
- تستخدم أسماء الأطباء ونطاقات الخدمات الموجودة في الصفحات المنشورة، دون
  اختلاق خبرات أو جوائز أو ترتيب أو أسعار أو نسب نجاح.
- «أفضل» و«أحسن» تأتيان في سياق أسئلة اختيار ومعايير مقارنة، وليس كادعاء
  تفوق مهني مثبت. لا توجد بيانات حجم بحث أو ترتيب Search Console متاحة في الاتصال الحالي.
- القسم مرئي ومقدم من الخادم، دون JavaScript جديد أو صور أو نماذج إضافية.
  يعالج أسماء CMS الداخلية والروابط canonical، ولا يضيف محتوى تخمينيًا
  لصفحة غير مراجعة. النصوص الأصلية محفوظة ولا يستبدل هذا الإصدار htmlContent في CMS.

## السرعة والاستقرار

- تعميم أولوية عرض صفحة شد الوجه الموجودة في أحدث Main على صفحات `/p/`:
  يظهر المحتوى دون حركة دخول الصفحة أو المؤشر الزخرفي أو شريط تحميل تجميلي.
  لا تؤجل نماذج الحجز أو أدوات القياس أو التتبع.
- إيقاف حركة المؤشر الزخرفي المخفي على الشاشات الصغيرة وأجهزة اللمس، وإيقاف
  حلقته عند سكونه على سطح المكتب، وتنظيف مستمعي الأحداث عند الإزالة.
- حذف بيانات `data-blocks` الخاصة بمحرر الصفحة من HTML الزائر فقط.
  عُثر عليها في أربع صفحات؛ الأصل المحفوظ في المحرر لا يتغير.
- قياس الأبعاد الأصلية لـ53 أصل صورة مستخدم فعليًا، وإضافة width/height عند
  غيابهما معًا لتقليل تحرك المحتوى. لا تتغير المصادر أو CSS أو تعليمات تحميل
  صريحة، ولا تُخمن أبعاد صورة غير معروفة، ولا يُضاف تحويل صور على خادم Render.
- لا تغيير لمعرّفات التتبع أو نماذج الحجز أو أرقام الاتصال أو رسائل واتساب.
  تظل سياسة CSP وحدود الذاكرة وتخزين الكتالوج كما في Main.

## التحقق

التقارير التفصيلية لكل صفحة وقياسات Lighthouse قبل وبعد محفوظة في مجلد
`docs/audits/2026-10-14/landing-pages` في مساحة العمل المرفقة. القياسات
مختبرية على الجوال وليست بيانات Core Web Vitals الميدانية أو إثباتًا للفهرسة.
تتأثر النتائج بالشبكة وحمل الجهاز والسكربتات الخارجية؛ تُعرض القيم لكل صفحة.

الاختبارات المركزة: `npm run test:landing-search` و`npm run test:csp`، مع
فحص الأنواع والبناء واختبارات المحتوى والحجز والتتبع والذاكرة قبل النشر.
يجري التحقق بعد النشر بطلبات قراءة فقط، دون إرسال حجوزات أو رسائل مرضى.

يمكن التراجع عن تغييرات العرض بإرجاع commit الإصدار. نسخة كود البطاقة قبل
حذفها محفوظة في AppLog؛ لا تعاد فوق تغييرات لاحقة للمشرف تلقائيًا.
